## Summary

This part of the Dataphor Developer’s Guide provides an introduction to Dataphor from the perspective of an application developer. It introduces all the terms, concepts, and technologies necessary to utilize Dataphor, and lays the groundwork for the declarative approach. The part is organized as follows:

**[Application Development Considerations](application-development-considerations.md#summary)**  
Discusses application development in general, the technical difficulties associated with building applications, and the declarative approach to application development as a solution to these problems.

**[Database Management Concepts](database-management-concepts.md#summary)**  
Provides a survey of database theory and database management systems in general.

**[Application Development Concepts](application-development-concepts.md#summary)**  
Discusses application development concepts in general and describes how the declarative approach can be applied to automate the development process.

**[Dataphor Product Anatomy](dataphor-product-anatomy.md#summary)**  
Provides a brief description of Dataphor product anatomy, and how it enables the declarative approach.

# System.NewGuid

**Declarations**

```d4
create operator .System.NewGuid() : System.Guid
 class "System.NewGuidNode" static tags { DAE.IsDeterministic = "False", DAE.IsRepeatable = "False" };
```

**Remarks**

`NewGuid` returns a new unique GUID. These GUIDs are generated by the system and are guaranteed to be globally unique.

**Using System.NewGuid**

```d4
select TableDee add { NewGuid() Guid };
```

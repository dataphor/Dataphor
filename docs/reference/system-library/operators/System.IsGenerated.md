**Remarks**

`IsGenerated` checks to see if the specified object was generated by the system, such as a scalar type selector or accessor. Generated objects can be either system or non-system.

**Using System.IsGenerated**

```d4
select IsGenerated("Binary");
select IsGenerated("Binary_System_String_");
select IsGenerated("IsGenerated_System_String_");
```

# System.Sleep

**Declarations**

```d4
create operator .System.Sleep(const AValue : System.Integer)
 class "System.SystemSleepNode" static tags { DAE.IsRemotable = "False" };
```

**Remarks**

`Sleep` stops the current process for the specified number of milliseconds.

**Using System.Sleep**

```d4
Sleep(2000);
```

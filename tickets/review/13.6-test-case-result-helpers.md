## What changed

- `tests/libraries/TestFramework.Coverage.Base/Documents/Tables.d4`: appended the table `CurrentCaseItems` (`Name`, `Passed`, `Message`, key `{ Name, Message }`, in the library's default device `Temp`) and the operator `RaiseCurrentCaseItem(const AName : String, const APassed : Boolean, const AMessage : String)`, which inserts a row and raises `Error(AName + ": " + AMessage)` when `APassed` is false. The raise is what makes a failed case fail the script, since `Transaction.Atomicity.Run`'s closing check is commented out. File kept UTF-8 without BOM, CRLF, tabs (checked with `od`). `Register.d4` unchanged (it already runs `Tables`).

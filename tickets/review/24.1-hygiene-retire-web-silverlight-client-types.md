- **`libraries/Frontend/Documents/Silverlight.NodeTypes.dnt` and `Web.NodeTypes.dnt`** — deleted. `Windows.NodeTypes.dnt` stays.
- **`docs/migration-notes.md`** — one new row at the end of the *D4, catalog and libraries* table: a freshly built catalog has one client type instead of three; an application that passes `Web` or `Silverlight` to `GetNodeTypes`, `GetApplicationNodeTypes`, `GetLibraryNodeTypes` or `GetLibraryFiles` now gets an error from the restriction on the table where it used to get a row; the deleted documents on their own change nothing because each load is guarded by `DocumentExists`; and an existing 3.x catalog is not modified and keeps all three rows, because the insert only runs when a catalog is first built and 4.0 catalogs are rebuilt rather than migrated — so there is deliberately no upgrade script and no `Frontend` library version bump.

## What a reviewer should check

- **The layout prune works, with one wrinkle worth knowing.** After `dotnet build Dataphor.slnx` (which builds Debug), `artifacts/layout/debug/Libraries/Frontend/Documents/` holds only `Windows.NodeTypes.dnt` — the two deleted documents are gone, with no clean needed, exactly as the ticket predicted. `artifacts/layout/release/.../Documents/` **still holds both**, because no Release build has run since the deletion; it is a stale untracked build output and it clears on the next Release build. CI builds both configurations, so this is not a gap, but a reviewer looking at the Release layout on this machine will see the old files.
- **Where the two names still appear.** A repository grep for `Silverlight` or `Web` still hits the error-code reservations, the two historical upgrade scripts, the user-guide history, `Setup/`, and now the new migration-notes row and the plan row. All deliberate — the list is in `hygiene-silverlight-conditionals`.
- **The judgement call in the migration note** is the one thing with prose rather than mechanism behind it: it states that no upgrade script is owed and the library version is deliberately not bumped. That follows the plan's rebuild-rather-than-migrate direction, but it is the sentence to read closely, since a reader of the note is an operator deciding whether their 3.x catalog needs attention.

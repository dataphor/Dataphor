The *Where* column is measured too, which corrected three entries (`LOGFILECACHEEVENTS` and `USESPINLOCK` are in the client protocol assembly, not the engine; `USESQLCONNECTION` is in the store assemblies).

The page states all of this in its own words, so a reader is not left wondering why it disagrees with the file in the history.

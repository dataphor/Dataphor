## What this is

An umbrella for the WS12 items after Phase 1, plus the two late WS1 clean-up items. When promoted to `plan/`, the planning agent replaces it with one ticket per item whose prerequisites are on the board, parks the rest as a new backlog ticket `debt-ws12-hygiene-later`, and deletes this file.

**Promote when** gate G1 holds, for `hygiene-silverlight-conditionals`; the rest wait on WS6 and WS9 tickets existing.

- `hygiene-remove-rest-leftovers` — delete `src/engine/DAE/REST/RESTResult.cs` and `src/engine/Server/REST/RESTMarshal.cs`, their `Compile` entries in `DAE.csproj` and `Server.csproj`, and the `Newtonsoft.Json` package reference in `Server.csproj` that only `RESTMarshal.cs` needs (the project file’s own comment says so; `DAE.NativeCLI.csproj` references the package for its own reasons and keeps it). Found by `test-coverage-report-tool`, which excludes the two paths from the coverage area map until they go (`tools/coverage-report/areas.json`, the `excluded` list, which names this arm) - drop that exclusion in the same change. No prerequisite.

No prerequisite. A fifth file of the same kind, found 2026-11-23 by `debt-debugger-coverage`: `src/engine/DAE/Debug/DebugContext.cs` (11 coverable lines, `public class DebugContext` and `public class DebugContexts`, `Compile` entry in `DAE.csproj`), a compile-time script/locator holder that nothing in the repository constructs - outside the file itself a grep of the whole tree for `DebugContext` finds nothing.

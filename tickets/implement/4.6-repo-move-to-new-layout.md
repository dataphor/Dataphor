## Edge cases & interactions

- **Historical text vs pointers.** A path in a dated measurement, a description of how things were, or the old → new table's left column is a record; a path that tells the reader where to look now is a pointer. Change pointers only. Verified by inspection; the reviewer will check the final `git grep` hits one by one.
- **Paths that did not move** (`Documentation/`, `Setup/`, `Utilities/`, `Images/`, `Dataphor/netsh_address_reservations.txt`, `legacy/…`, `tools/net-spike/`) must not be "fixed". Verified by inspection.
- **Markdown links** must resolve: every relative link edited here points at a path in `git ls-files` (check each one; a small script over the edited files is fine).
- **Encoding.** `AGENTS.md` is UTF-8 without BOM; the docs and rules files are UTF-8/ASCII with LF. Keep them; do not hard-wrap (one paragraph per line).
- **Privacy.** No customer names or paths enter the docs (the repository is public).

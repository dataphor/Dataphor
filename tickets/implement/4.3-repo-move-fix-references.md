## Edge cases & interactions

- **References inside a project's own folder** must come out byte-identical; a change there means the mapping is wrong. Verified by inspecting `git diff -U0`.
- **Case.** Old values may spell a folder in another case (`Dataphor\DAE.SQLite` vs `dae.sqlite`); match case-insensitively. The `System.Data.SQLite.DLL` file name keeps its upper-case extension in the new path. Verified by the resolution check (it compares against `git ls-files`, which is case-exact).
- **Encoding.** Project files are UTF-8 with BOM and CRLF; the solution is ASCII CRLF; spike files and `.gitignore` are ASCII LF; `index-config.json` and `migration-notes.md` are LF. Preserve each (`file` before and after). - **NuGet `packages/` is not restored** in this checkout, so references into it cannot be resolved on disk; they are checked by shape only (they all point at `<root>/packages/<id>.<version>/…`).

## Code-block tags: the rules applied, and the 76 changed rows

Reviewed page by page from the scratch output, reading each block with the sentence that introduces it ("In SQL we write:" / "The equivalent in D4 is:"). Rules:

- `bnf`: productions (`::=`) and syntax templates written with `<placeholder>` non-terminals even without `::=` (operator-signature templates, event-handler signatures).
- `d4`: D4 statements, expressions, bare literals and identifiers given as examples of D4 syntax, signatures in D4 syntax without placeholders, and document expressions.
- `sql`: SQL for a back end, including what `D4ToSQL` prints.
- `csharp`: C# script actions in forms and C# host signatures.
- `text`: query output, plan output, tag syntax lines (`Frontend.Query = "<table expression>"`), command lines, and the one pseudo-query that mixes SQL and D4 (`select Employee cross join EmployeePhone where …`: the D4 parser would reject it).
